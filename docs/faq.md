# Questions fréquentes

??? question "C'est vraiment gratuit ?"
    Oui. L'accès est gratuit. Une participation libre aide à acheter des outils et des pièces.

??? question "Faut-il s'inscrire à l'avance ?"
    Non, venez directement pendant les horaires de l'atelier. Les dates sont indiquées sur la page d'[accueil](index.md).

??? question "Que puis-je apporter ?"
    Tout objet que vous pouvez porter : petit électroménager, vêtements, vélos, jouets, ordinateurs. Pensez aux accessoires.

??? question "Mon objet sera-t-il forcément réparé ?"
    Non, mais nous essayons toujours. Quand la réparation est impossible, nous vous expliquons pourquoi.

??? question "Je ne sais pas bricoler, puis-je devenir bénévole ?"
    Oui. Il y a aussi besoin d'aide pour l'accueil, l'orientation et l'organisation. Voir la page [Rejoindre](rejoindre.md).

??? question "Qui est responsable si l'objet casse davantage ?"
    Les réparations se font à vos risques, avec l'aide de bénévoles non professionnels. Le Repair Café ne peut pas être tenu responsable. À préciser avec l'organisateur.
