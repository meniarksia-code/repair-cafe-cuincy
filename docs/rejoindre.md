# Rejoindre le Repair Café

## Venir faire réparer un objet

1. Apportez votre objet (et ses accessoires : chargeur, câble, pièces cassées).
2. Inscrivez-vous à l'accueil à votre arrivée.
3. Un bénévole s'installe avec vous pour diagnostiquer la panne.
4. Réparez ensemble, puis repartez avec votre objet.

!!! tip "Bon à savoir"
    Les bénévoles vous accompagnent, mais c'est vous qui réparez. Prévoyez un peu de temps, surtout si l'atelier est très fréquenté.

## Devenir bénévole

Vous savez coudre, bricoler, dépanner un ordinateur ou réparer un vélo ? Il n'y a pas besoin d'être expert : vous pouvez aussi accueillir, orienter ou tenir la caisse de participation.

Pour nous rejoindre, passez nous voir à un atelier ou écrivez-nous depuis la page [Contacts](contacts.md).
